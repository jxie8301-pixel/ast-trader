# 模块：theme_purity —— 题材纯度去伪存真

## 输入

- 标的：{name}（{ticker}）
- 命中题材 / 概念：{concepts}
- 主营构成（分部名称 + 营收占比）：{business_composition}
- 公告 / 报告证据片段：
{evidence}

## 任务

判断这些题材是**真受益**还是**蹭概念**。

判定要点：
1. **主营占比**：题材相关业务占营收比重多少？占比过低（< 10%）通常是蹭概念。
2. **落地证据**：有无订单、产能、认证、并表收入？只有"战略合作/意向框架"而无落地，判为伪。
3. **供应链定位**：是直接供应商，还是仅"参股/关联/间接"？
4. **时间维度**：是已经产生收入，还是"未来计划布局"？

## 特别禁止

- 不许因为概念名字好听就判真。
- 无落地证据但疑似炒作的，**不要直接给结论**，而是通过 `nominations`
  提名「题材无业绩支撑」类风险（这才是你的权限）。

## judgment 取值

`真实受益` / `部分受益` / `蹭概念` 三者之一。
拿不到主营占比与落地证据时，`abstained` 置 true。

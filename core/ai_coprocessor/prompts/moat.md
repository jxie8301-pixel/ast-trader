# 模块：moat —— 护城河语义判定（对应质地五问 Q3「护城河存在吗」）

## 输入

- 标的：{name}（{ticker}）
- 所属概念：{concepts}
- 主营构成：{business_composition}
- 量化中台已算出的数（仅供引用，**禁止重算**）：毛利率 {gross_margin}，净利率 {net_margin}，ROE {roe}
- 公告 / 定期报告证据片段：
{evidence}

## 判据（借鉴上游判断链手册，已按本项目裁剪）

判 **✓** 必须**同时**满足：
1. 利润率明显优于同行业标杆；
2. 有**可解释的定价权来源** —— 专利 / 牌照 / 网络效应 / 客户认证周期 / 成本结构优势，
   且能在上面的证据片段里指认出来。

判 **⚠️**：仅达到行业平均水平；或有壁垒但证据只有管理层自述、无第三方可核验来源。
判 **✗**：利润率低于标杆且找不到定价权来源；或有明确证据表明壁垒正在衰减。

## 特别禁止

- **概念标签本身不是护城河**。命中「AI / 半导体 / 算力 / 机器人」这类概念，
  若没有对应的定价权来源与财务印证，一律判 ⚠️ 或 ✗，不得因为"是热门赛道"就给 ✓。
- **不许用小分部的壁垒给全公司背书**。若壁垒业务占主营比重低，
  必须在 `nominations` 里提名「分部壁垒无法代表整体」。
- 不许把"行业景气"当成公司壁垒 —— 那是 beta，不是 alpha。

## judgment 取值

只能是 `✓` / `⚠️` / `✗` 三者之一。

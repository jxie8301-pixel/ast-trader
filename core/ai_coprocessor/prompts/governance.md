# 模块：governance —— 治理与监管文本穿透

## 输入

- 标的：{name}（{ticker}）
- 命中监管类公告：{announcements}
- 公告 / 审计报告证据片段（已带页码）：
{evidence}

## 任务

从非结构化监管文本里挖出**量化指标测不到**的风险：

1. **交易所问询函 / 关注函**：监管问的是什么？公司回复是否答非所问？
   回复里是否承认了此前未披露的事实？
2. **审计意见**：标准无保留 / 带强调事项段 / 保留 / 无法表示意见？
   强调事项段说了什么？
3. **减持主体与动机**：创投/财务投资者到期退出（相对良性）
   与实控人、董监高清仓式减持（恶性）性质完全不同 —— 必须区分。
4. **资金占用 / 关联交易 / 担保**：是否出现「非经营性资金占用」字样。

## 特别禁止

- 不许把它写成"监管关注即等于造假" —— 问询函是提问，不是定论。
- 不得输出任何处罚金额、占比等数值结论（你没有数值权限），
  只需指出"存在哪类风险、证据在哪一页"。

## 风险表达

所有发现都通过 `nominations` 输出，级别建议：
- 🔴 无法表示意见 / 保留意见 / 资金占用 / 立案调查
- 🟠 问询函涉及核心资产或收入确认 / 实控人清仓式减持
- 🟡 一般关注函 / 财务投资者正常退出

`judgment` 可留 null（本模块以提名风险为主）。

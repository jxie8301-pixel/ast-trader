# AST-Trader 终局演进思路与「双引擎融合」架构白皮书

> **系统演进愿景**：从「纯代码确定性量化审计引擎」迈向「量化确定性底座 + 语义大模型协处理器」的双引擎融合投研体系。

---

## 1. 战略背景与技术路线反思

在系统的迭代过程中，我们深入对比了两种截然不同的投研技术路线：

| 对比维度 | 纯大模型多代理流派 (如 Ashare-researchreport) | 纯代码确定性量化流派 (AST-Trader 当前架构) |
| :--- | :--- | :--- |
| **底层驱动** | 10 个 LLM Sub-Agents 多轮对话编排 | Python 本地量化算法、审计模型与盘口规则 |
| **出报耗时** | **15 ~ 30 分钟** / 股 (极度迟缓) | **1 ~ 2 秒** / 股 (毫秒级即时推导) |
| **资金与Token成本** | 单次消耗 **$10 ~ $40** 大模型 API 费 | **0 成本** (本地完全免费离线运行) |
| **算术与因果严谨性** | 存在大模型算术幻觉、前后矛盾风险 | **100% 确定性**，严密数学闭环，零幻觉 |
| **A股短线/盘口博弈** | **完全缺失** (看不见挂单、主力对倒与连板) | **深度穿透** (L2微观、聪明的钱 $Q$、异动监管) |
| **年报长文本穿透** | **极强** (可精读 200 页 PDF 附注与公允价值) | **偏弱** (受限于结构化数据与预设标签) |
| **全市场批量筛选** | **不可行** (5300只股票需几十万美元与数周) | **极强** (15 秒完成全市场 3 层漏斗收敛) |

### 核心认知结论：
* 纯大模型流派是**“昂贵的侦探”**：适合中长线基本面投资者在周末花半小时和几十美元深扒一家公司的历史财报底稿，但**完全无法用于 A 股实盘短线博弈、盘中决策与全市场高频选股**；
* 纯代码量化流派是**“敏捷的特战参谋”**：在防守扫雷、微观敌情侦察（L2盘口）、算术闭环与极速决策上拥有压倒性优势，但**在非结构化中文文本（如年报附注、重组小作文、互动易语义）的深层理解上存在短板**。

因此，终局演进绝不是“用 AI 推翻现有代码”，而是**让大模型站在量化基座之上，形成「双引擎分工融合架构」**。

## 2. 终局演进架构：双引擎融合模型 (Dual-Engine Architecture)

```mermaid
flowchart TD
    subgraph 引擎一_量化确定性底座 [Engine 1: Quantitative Core (Non-Negotiable)]
        A1[实时行情与L2十档盘口] --> B1[微观盘口防伪与聪明的钱Q因子]
        A2[财务三表与治理数据] --> B2[11项会计审计扫雷与5期ROE DuPont]
        A3[全市场天梯与指数动量] --> B3[反向DCF与SOTP叙事估值双锚]
        B1 & B2 & B3 --> B4[主力7阶段状态机与实战双轨战术]
        B4 --> C1[硬核计算指标字典 & 致命红旗锁死]
    end

    subgraph 引擎二_AI语义协处理器 [Engine 2: LLM Coprocessor (Semantic Enrichment)]
        C1 --> D1[结构化数据包 + 公告/新闻原文 Prompt 注入]
        D1 --> E1[本地/轻量大模型: DeepSeek-R1 / Qwen2.5 / Ollama]
        E1 --> F1[任务1: 生成 3-5 句精辟买方导读]
        E1 --> F2[任务2: 年报附注与非标审计异常语义提炼]
        E1 --> F3[任务3: 红蓝逻辑对决与证伪假设挑战]
    end

    subgraph 最终交付物 [Final Output]
        C1 -.->|提供绝对真实的硬指标底座| G[双模研报: 终端决断卡 + 离线HTML]
        F1 & F2 & F3 -.->|注入深层语义洞察与生动表述| G
    end
```

### 2.1 架构铁律与边界守则 (Guardrail Rules)
为了杜绝大模型破坏量化系统的确定性与严肃性，系统制定以下**不可逾越的架构红线**：
1. **严禁 AI 算账（No Arithmetic by LLM）**：
   * 所有财务比率、DCF 折现值、SOTP 估值区间、涨停晋级率、监管余量百分比，**永远由 Python 确定性代码计算，绝对禁止让大模型重新计算或覆盖修改**。
2. **严禁 AI 篡改决断档位与止损线**：
   * 致命红旗的一票否决权（封顶为回避）、仓位上限（Position Cap）与 T+1 铁律止损价，由 `LintValidator` 最终裁定，大模型仅能作为表述润色者，无权更改档位。
3. **数据流单向传递（Unidirectional Data Flow）**：
   * 数据流只能从「量化基座 $\rightarrow$ AI 协处理器」，严禁将 AI 的定性猜测作为量化指标的输入参数，避免形成逻辑闭环污染。

## 3. 三阶段演进实施路线图 (Three-Phase Roadmap)

### 阶段一：纯代码确定性量化基座建设（✅ 当前已圆满完成）
* **核心成果**：
  * 通达信 L2、财务三表、治理概念全通道数据采集与健康度审计（`DataHealthTracker`，零静默 pass）；
  * 首页「赚不赚钱」数据看板与 Unicode Sparkline 迷你走势；
  * 支柱 ❶~❺ 买方因果闭环研报中枢；
  * 主力 7 阶段生命周期状态机与 L2 聪明的钱高频 $Q$ 因子；
  * 全市场连板天梯、宏观大盘水温与短线三层漏斗筛选；
  * 单股分析与离线响应式 HTML 研报生成；
  * 558 项端到端全覆盖自动化测试套件（537 项离线 + 21 项 `seednet` 联网种子跑批）。

---

### 阶段二：本地轻量级 AI 语义协处理器接入（📅 近期演进重点）
* **设计目标**：在不增加昂贵 Token 成本、保持秒级响应（<5秒）的前提下，补齐自然语言理解短板。
* **技术选型**：
  * 支持接入本地部署的轻量开源大模型（如 `Ollama: deepseek-r1:8b`、`qwen2.5:7b-instruct`）或极低成本的 DeepSeek API。
* **功能落地矩阵**：
  1. **买方导读与核心矛盾润色 (`Buyer Summary Coprocessor`)**：
     * 输入：计算完成的 5 支柱结论、主力阶段、估值双锚、数据缺口；
     * 输出：3~5 句极具买方洞察力的定性小结，替换原有的固定模板语句。
  2. **年报附注与公告非标挖掘 (`Footnote Miner`)**：
     * 利用轻量模型对财报中“公允价值变动明细”、“关联交易方担保”、“诉讼与存货跌价准备”的文本附注进行针对性问答，提取非结构化异常证据。
  3. **红蓝对抗评审员 (`Adversarial Reviewer`)**：
     * 由一个轻量 Agent 专门扮演空头合规官，对当前标的的做多逻辑提出 2 个最犀利的“证伪反例”，强化风控深度。

---

### 阶段三：云端/混合多智能体深度研报选配模式（🔭 远期规划）
* **设计目标**：针对投资组合中的重仓标的或重点产业中军，提供“一键升级深度长篇研报”的选配功能。
* **使用场景**：
  * 用户运行普通模式时，默认 1 秒跑出标准量化决断卡；
  * 用户追加参数 `--deep-ai` 时，触发深研流水线：
    * 异步下载并精读近 3 年年报完整 PDF 原文；
    * 调取券商深度研报与行业协会统计年鉴；
    * 产出数十页包含图表、引用出处页码、产业链上下游溯源的万字买方立项报告。

## 4. 阶段二落地的数据契约与接口原型设计 (Draft Contract)

为后续接入阶段二 AI 协处理器，系统规划的标准交互接口如下：

```python
# 规划中的 AI 语义协处理器接口契约
class AISemanticCoprocessor:
    """AST-Trader 语义增强协处理器 (基于本地轻量 LLM / DeepSeek)."""

    def __init__(self, provider: str = "ollama", model: str = "deepseek-r1:8b") -> None:
        self.provider = provider
        self.model = model

    def enrich_decision_card(self, card: dict[str, Any], raw_texts: dict[str, str]) -> dict[str, Any]:
        """为已算好的量化决断卡注入深层语义洞察 (绝不改动数值与档位).
        
        Args:
            card: 纯代码计算完毕的标准决断卡 (包含 5 支柱全部数值与档位)
            raw_texts: 包含公司最新公告摘要、F10业务阐述、定期报告附注等原文
            
        Returns:
            富集了买方导读、附注审计与证伪反例的增强决断卡
        """
        # 1. 组装只读 Prompt (包含硬指标约束)
        prompt = self._build_enrichment_prompt(card, raw_texts)
        
        # 2. 调用轻量模型生成语义洞察 (设置严格的 JSON Schema 输出)
        ai_response = self._invoke_llm(prompt)
        
        # 3. 校验并挂载至增强字段 (安全合并，物理隔离硬指标)
        card["ai_executive_summary"] = ai_response.get("summary")
        card["ai_footnote_findings"] = ai_response.get("footnote_findings")
        card["ai_devil_advocate"] = ai_response.get("thesis_risks")
        
        return card
```
